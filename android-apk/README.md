# GoalTask Android

APK nativo do GoalTask com placar flutuante e notificações de gol.

## Uso

1. Instale o APK e abra o GoalTask.
2. Toque em **Ativar placar**.
3. Autorize **aparecer sobre outros apps** e as notificações.
4. Arraste o placar para qualquer posição da tela.
5. Toque no placar para voltar ao aplicativo.

O serviço consulta a API pública do GoalTask a cada 15 segundos. O aplicativo não contém a chave do provedor de futebol.
